# Retrospective Reflection

## What Went Well
Overall, this project went well and helped me gain more experience with both web development and project planning. One thing that went especially well was organizing the structure of my website and successfully creating multiple pages using HTML. I also became more comfortable working with GitHub and uploading my project files.

## Challenges Faced
The biggest challenge I faced during the project was styling the website with CSS. It took time to make the pages look the way I wanted, and I had to experiment with different styles before finding something that worked well.

Another issue I ran into was getting my links to work correctly on GitHub Pages. The link to my Index page from my About worked when I opened the files directly from my computer, but it did not work properly once the project was uploaded to GitHub. After troubleshooting, I realized the issue was related to GitHub just taking a little longer to process the request.

## What I Would Do Differently
If I could do this project again, I would spend more time planning the styling before I started coding and test the website on GitHub Pages earlier in the process. This would help me catch link and deployment issues sooner instead of waiting until the end.

Overall, the project helped me improve my problem-solving skills and gave me more confidence in building and managing a web development project.
