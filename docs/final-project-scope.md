# Project Scope Statement  
## Project 03 – Final Project  
**Project Manager:** Mia Singleton  






## Project Purpose / Justification
The purpose of this project is to design and develop a professional personal portfolio website while applying project management principles. This project will demonstrate both technical web development skills and the ability to plan, organize, and manage a project from start to finish.






## Project Description
This project will expand my current personal website into a two-page portfolio website. The website will include a homepage and a secondary About page, styled with a single external CSS file.


In addition to the website, a full set of project management documentation will be created and stored in a GitHub repository. The website will be published using GitHub Pages.






## Project Objectives
- Create a two-page website
- Apply consistent styling using CSS
- Organize content clearly and professionally
- Demonstrate use of GitHub for version control
- Create supporting project documentation
- Publish a live website






## Deliverables
- `index.html` (homepage)  
- `about.html` (second page)  
- `style.css` (shared stylesheet)  
- `README.md` (project overview)  
- `docs/scope.md`  
- `docs/plan.md`  
- `docs/retrospective.md`  
- Live GitHub Pages website  
- GitHub repository with commit history  






## In Scope
- Building a two-page static website  
- Creating and organizing project documentation  
- Styling the website using CSS  
- Publishing the project online  






## Out of Scope
- Backend development  
- Advanced JavaScript functionality  
- User authentication or databases  






## Constraints
- **Time:** Must be completed within course deadlines  
- **Budget:** No budget; free tools only  
- **Skills:** Limited to beginner-level HTML and CSS  






## Assumptions
- GitHub Pages will be used for hosting  
- All required tools will be accessible  
- Existing website will serve as a foundation  






## Success Criteria
- Website includes two functional pages  
- All required documentation is completed  
- Site is published and accessible online  
- Code is clean and well-organized  
- Project meets all rubric requirements
