# Project Overview

This project involves the design and development of a personal portfolio website using HTML and CSS. The website highlights my academic background, career goals, technical interests, and hobbies while demonstrating foundational web development skills.

The project was created as part of a web development assessment to practice semantic HTML structure, external CSS styling, Git version control, and GitHub Pages deployment.

---

# Project Objectives

- Create a responsive and organized personal portfolio website
- Practice semantic HTML and external CSS styling
- Demonstrate understanding of project management principles
- Publish a live website using GitHub Pages
- Gain experience using Git and GitHub for version control

---

# Project Scope

# Risk Analysis (TAME Framework)

| Risk | Tolerate | Avoid | Mitigate | Eliminate |
|---|---|---|---|---|
| HTML syntax errors | Minor formatting issues may be tolerated during development | Avoid rushing code implementation | Test pages frequently in browser | Validate code before submission |
| CSS styling inconsistencies | Small visual differences between browsers may be acceptable | Avoid overly complex styling | Use consistent formatting and testing | Simplify CSS structure |
| GitHub Pages deployment issues | Temporary deployment delays may occur | Avoid incorrect file paths | Double-check repository settings | Verify docs folder structure |
| File organization problems | Minor naming issues can be corrected | Avoid inconsistent naming conventions | Maintain organized folder structure | Review all files before upload |
| Broken navigation links | Small issues may happen during development | Avoid moving files after linking | Test all links before publishing | Final site testing prior to submission |
